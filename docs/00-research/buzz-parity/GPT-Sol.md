## 1. 결론

**추천은 방향 4(전환 판정·G1 전 기능 동결)입니다.** 11-10–11-16에는 인벤토리·수용 기준·읽기 전용 계약 검토만 착수하고 관찰 대상 실행 경로는 유지합니다. 11-17은 자동 해제일이 아닙니다. 7일 증거에 대한 전환 판정과 G1 결과를 확인한 뒤 영환님이 다음 구현 범위를 결정해야 합니다.

동결 해제 뒤에는 Jarvis 사용 완결성을 기준으로 **일반 문서 첨부 → 한국어 메시지 검색 → Jarvis 처리 상태**를 먼저 검토합니다. 버튼 승인은 기존 텍스트 승인으로 대체 가능하므로 뒤에 둡니다. 일반적인 Slack 기능 수를 채우는 목표는 채택하지 않습니다.

**관찰 창 중 기능 코드·DB·설정·배포·어댑터·푸시 경로 변경은 보류**합니다. 순수 웹 변경도 전송·열람·알림 탭 경로에 영향을 줄 수 있으므로 안전하다고 일괄 면제하지 않습니다. 관찰을 막는 실제 결함은 별도 복구 결정 대상으로 분리하고, 담당자가 변경 영향과 7일 관찰 재시작 필요 여부를 기록해야 합니다. 본 검토는 그 수정을 승인하지 않습니다.

## 4. 사실 / 추정 / 확인 필요

### 사실

1. PRD는 핵심 사용자를 영환님 1명과 Jarvis로 정의하고, 텍스트 승인을 이미 P0에 포함합니다(E1,E5).
2. 문서 첨부와 typing은 읽은 어댑터에서 각각 fallback/no-op입니다. 일반 음성 전송과 standalone cron 첨부는 서로 다른 경로입니다(E13,E14).
3. 읽은 QA 문서는 G1 불가·전환 미검증을 기록합니다. 이 보고서가 11-10 실관찰 결과를 새로 수집한 것은 아닙니다(E7,E8).

### 추정

1. 검색·문서 첨부·처리 상태가 일반 presence·그룹 DM보다 높은 개인 사용 가치를 제공합니다. 빈도·가치·순서는 모두 제품 판단입니다.
2. 기존 텍스트 승인이 정상 동작한다면 버튼·clarify UI는 전환 필수보다 사용성 개선에 가깝습니다. 실제 막힘이 확인되면 순위를 올립니다.
3. 동결은 관찰 원인 분리를 돕지만 문서 검토까지 막을 이유는 없습니다. 안전한 준비와 실행 변경을 구분하는 제안입니다.

### 확인 필요

1. 11-10 이후 6개 전환 기준의 실제 기록과 최신 G1 판정. 과거 QA의 PASS·FAIL을 현재 배포 결과로 확대하지 않습니다.
2. 한국어 고유명사·복합어·띄어쓰기·부분어 기대 수준과 실제 FTS 품질. PostgreSQL FTS 사용 자체를 한국어 품질 충족으로 보지 않습니다.
3. PDF·텍스트 등 최초 허용 형식, 크기·보존 상한은 정본에서 결정합니다. 수치를 이 보고서에서 새로 고정하지 않습니다.
4. 봇 채널 제안의 Q1–Q8, 구조화 clarify 필요성, 원격 세션 폐기 계약은 해당 담당 후속 검토가 필요합니다. Git 금지에 따라 브랜치에만 있는 봇 채널 문서는 열지 않았습니다.
5. cron 음성 브리핑이 실제로 어느 호출 경로를 거치는지와 첨부 도착 증거. E14는 경로 공백을 보여 주지만 배포 결함 확정은 아닙니다. 새 parity 기능으로 포장하지 말고 기존 전환 기준의 증거로 먼저 확인해야 합니다.

### 5-2. 단계·하지 말 것

1. **지금:** 방향 4와 검토 백로그만 채택 여부를 정합니다. 이번 라운드 산출물 외 파일·코드·설정은 바꾸지 않습니다.
2. **관찰 종료·G1 확인 후:** 방향 1을 실행 원칙으로 1–3번의 실제 막힘을 확인해 항목별로 착수합니다. 검색도 핵심 결과 회수 문제로 취급하며 일반 메신저 확장 묶음에 종속시키지 않습니다.
3. **첫 확장 검증 후:** 4–7번은 실제 세션 관리·승인 마찰·주제 분리 수요에 따라 재정렬합니다. 봇 채널은 문서 결정 전 구현하지 않습니다.
4. **후속 사용 증거 후:** 8–10번을 검토합니다. 저장·고정·파일 목록·예약·Electron을 동시에 늘리지 않습니다.
5. **이번에 하지 않을 것:** Slack 실환경 조사·브리지·에셋 재사용, 기업/통화/제3자 앱 범위 부활, Redis·외부 검색 서비스 추가, 본문 영구 오프라인 캐시, 11-17 자동 전환 선언을 하지 않습니다.

### 5-3. 영환님 결정 후보(번호)

1. **권고:** 방향 4를 지금 채택하고, 기능 변경 동결 해제는 전환 판정 및 G1 확인 뒤 별도로 결정합니다.
