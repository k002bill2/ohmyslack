## 준비

1. 테스트용 채널 하나(예: `#qa-ime`)를 열고, 같은 채널에 멘션 후보가 될 다른 멤버가 1명 이상 있는지 확인합니다.
2. 각 칸을 시작하기 전에 작성기를 비웁니다. **예외: ②와 ③은 하나의 연속 실행입니다** — ② 뒤 작성기에 남은 `안녕`을 지우지 않고 그대로 ③을 진행합니다. 전송 여부는 메시지 목록에 새 항목이 생기는지로 판단합니다(전송 1회 = 새 항목 정확히 1개).
3. macOS는 입력 소스를 「두벌식」으로, iOS는 「한국어」 키보드로 둡니다. iOS는 실제 손가락 입력(미러링·하드웨어 키보드 아님).

## 매트릭스 — 7항목 기대 결과 (§7-4 보조 규칙 5, 우선순위 1–5)

| # | 항목 | 입력 방법 | 기대 |
|---|---|---|---|
| ① | 조합 중 Enter 미전송 | `한` 처럼 마지막 글자가 조합 중(밑줄) 상태에서 Enter | 전송 0. 조합 글자가 확정될 수는 있으나 사라지거나 중복되지 않음(우선순위 1) |
| ② | 확정 Enter 미전송 | `안녕` 입력 → 조합 확정용 Enter 1회 | 전송 0, 작성기에 `안녕` 그대로(우선순위 2 확정 Enter 창) |
| ③ | 확정 후 독립 Enter 1회 전송 | ② 직후 작성기를 비우지 않고 잠시(1초 정도) 뒤 Enter 1회 | 전송 정확히 1회, 본문 `안녕`(훼손 없음), 작성기 비워지고 포커스 유지(우선순위 5) |
| ④ | 마우스(탭) 확정 후 Enter 전송 | `가나` 입력 중 작성기 안 다른 곳을 클릭(iOS: 탭)해 조합 확정 → Enter | 전송 1회, 본문 `가나`(100ms 후 확정 창 자동 해제) |
| ⑤ | 조합 중 Shift+Enter 입력 훼손 없음 | `다라` 조합 중 Shift+Enter(iOS: 키보드 줄바꿈 키가 있으면 해당 키) | 전송 0, 조합 글자 훼손·중복 0. 줄바꿈 여부는 IME에 맡김(우선순위 1) |
| ⑥ | 멘션 후보 열림 상태 Enter = 선택 | 조합 중이 아닐 때 `@` 입력 → 후보 열림 → (필요 시 한글 이름 일부 입력) → Enter | 후보가 선택되어 멘션 삽입, 전송 0. 선택과 전송이 동시에 일어나지 않음(우선순위 3) |
| ⑦ | 연속 빠른 입력 훼손 없음 | `안녕하세요 반갑습니다` 를 빠르게 입력 → 독립 Enter | 전송 1회, 본문이 입력과 정확히 같음(글자 누락·중복·자모 분리 0) |
